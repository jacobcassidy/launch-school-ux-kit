# SVG assets

SVG files imported by source code live under [`src/svg`](../../src/svg). Only referenced files are included in the userscript build.

The current project identity lives in [docs/branding](../branding/README.md), with full logos for light and dark backgrounds, transparent PNG exports, and previews. Three ascending squares represent steady progress toward mastery and the kit's modular UI components. The SVGs combine vector squares with embedded raster lettering; the wordmark is not outlined vector text. No separate standalone mark is supplied.

Unused icon alternatives and older assets live in the [design archive](../design/README.md) under [`docs/design/svg-reference`](../design/svg-reference). Preserve their hierarchy when reviewing them. Move an asset into `src/svg` and update its source reference when adopting it.

The archive includes the Launch School logo asset and unused Lucide icons. The project does not record the exact source revision for the vendored Lucide files; see [third-party notices](../../THIRD-PARTY-NOTICES.txt) for license details.
