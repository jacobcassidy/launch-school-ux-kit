# Repository preferences

- Create a separate Git commit for each completed task or feature. Finish the implementation and relevant checks before committing.
- Commit only changes belonging to that task or feature; leave unrelated user edits uncommitted.
- Follow the established commit-message style: use a concise imperative subject starting with a capitalized verb (for example, `Add demo video`). Do not use Conventional Commit prefixes such as `feat:`, `fix:`, or `docs:`.
